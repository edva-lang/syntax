# Syntax Gallery & Preview Suite

A curated collection of polyglot source code samples and data configurations.

## Overview
This gallery is designed to validate text renderers, stream tokenizers, and syntax engines across diverse grammars.

- **Fast Streaming**: Tokenization across line boundaries
- **Multi-language Support**: Highlighting keywords, strings, comments, numbers, types
- **Theme Testing**: ANSI 24-bit truecolor, bold, dim, and terminal palettes

> "Simplicity is prerequisite for reliability." — Edsger W. Dijkstra

| Language | File Extension | Paradigm |

| **Rust** | `.rs` | Safe Systems |
